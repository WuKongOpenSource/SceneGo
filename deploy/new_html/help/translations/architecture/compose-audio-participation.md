# 成片合成中的音频参与规则

## 影响分析

合成工作进程在拼接前规范化每段选中视频。在 `video_original` 模式下，有音轨的视频使用自身声音；分镜参考配音及其元数据不参与该片段的输入。必须在解析或探测参考文件之前作出这个判断，避免未使用的参考文件阻断合成。

无声视频沿用原有的参考音频回退方式。明确指定的 `reference_dubbing`、全局音乐和音效、字幕烧录、裁剪偏移、输出登记保持原契约。

本项不修改数据库结构、任务提交、点数或通知。不重映射合并分镜子项，不暗中放宽文件权限，不修复生产数据，也不重启合成。工作进程实际使用逐镜头参考，不是编辑器音频来源 ID 映射；未来跨镜头参考功能必须基于这一真实契约设计。

两个合成页面通过共用提示显示服务器已有错误，文本经过转义，不执行错误中的 HTML，也不增加诊断接口或暴露隐藏服务器元数据。空错误使用有帮助的兜底提示。

## 回归要求

- 视频原声模式不解析未使用的旧参考配音或分段参考配音。
- 未使用配音的非法时长不能阻断有声视频合成。
- 无声视频回退及明确选择的参考配音仍使用参考文件。
- 合成失败提示支持缺失文本与不可信文本。
- 合成服务、DAO、路由、前端测试、构建和契约检查通过。
