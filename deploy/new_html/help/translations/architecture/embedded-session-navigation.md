# 内嵌工作区登录与会话

## 影响与职责

专业画布和旧管理控制台与主应用共用已鉴权 HTTP 客户端。HTTP 401 仍会清除相应的过期浏览器会话并要求服务器鉴权，绝不因此开放匿名访问。

客户端位于同源内嵌页面时，由外层页面负责跳转登录。若仅把子页面跳到登录页，登录页面的防嵌入策略会阻止展示，导致不可用的灰色区域。

重新登录后的返回目标保留同源外层 URL，包括项目、分集、查询参数与锚点。不得跳转跨域或无法读取的父页面。独立页面的跳转行为保持不变。

仅专业画布 HTML 入口别名允许同源祖先嵌入。资源路径、任意嵌套文档、登录页和其他应用页面仍受保护。这不扩大脚本权限，也不允许其他来源嵌入。

## 不变的契约

没有数据库迁移、工作区快照、接口载荷、媒体转换、生成提交、点数扣除或通知变更。会话跳转不会取消后台生成。

主应用与专业画布构建都导入共享客户端，发布该变更时必须一起重新构建。本地验证不等于生产部署。

## 回归要求

- 内嵌画布会话过期时，同源外层页面跳转到登录。
- 重新鉴权后保留项目画布返回地址。
- 独立页面、跨域父页面和不可访问父页面场景仍然安全。
- 专业画布 HTML 别名仅接受同源嵌入。
- 登录页和非入口文档继续禁止嵌入。
