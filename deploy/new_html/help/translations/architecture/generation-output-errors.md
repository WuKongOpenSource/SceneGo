# 生成输出与供应商错误约定

Seedance 的输出默认值由 Seedance 自己定义，而不是沿用共享请求模型的 Wan 默认值。未指定清晰度时，可见的生成面板和提交请求均为 720p。历史大写值会被规范化；明确指定的非法或不支持值会被拒绝，而非静默降级。

普通版和公开版任务适配器共用前端辅助函数，包括通用视频提交。请求模型在入队、访问关联写入和预留点数前进行校验。供应商适配器还会按最终解析的模型再次校验，同时保留通道专属模型路由、媒体角色、原图处理和请求时长。

供应商计费失败也可能返回 HTTP 403。图片适配器先按结构化配额错误码分类，再判断鉴权状态，并返回长度受限的安全提示。不会暴露凭据、上游账户标识或余额，也不切换供应商、不改变点数账本、已保存图片和自动重试策略。真实供应商余额问题由运营人员处理。

## 验证边界

> 本节测试数量和历史基线问题均来自原文所记录的版本，不代表当前在线环境的实时状态。

回归覆盖缺省和大写清晰度、提前拒绝、普通与公开任务适配器、生成面板状态保留、实际入队载荷、媒体持久化、原图来源、计费和通知。这些契约检查不需要真实付费生成。

原文记录：未修改的主分支基线有三个既有架构检查失败：
- `check_api_config_runtime_loader.py`：Seedance 标准模型没有投影到子模型环境变量。
- `check_admin_api_config_crud.py`：预设门面数量变为 25。

使用原始基线 Python 模块替换补丁后，三项失败都可复现，分别归属供应商配置、目录契约和在线状态持久化；本项不修改这些模块或夹具。其余七项架构检查通过。

原文这一阶段的完整前端测试通过 1,241 项，保留三个既有待办；TypeScript、普通构建和公开构建通过。后端重点及相邻测试通过 194 项，包括媒体持久化、路由、工作进程、点数和通知。
