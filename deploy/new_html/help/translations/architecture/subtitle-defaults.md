# 字幕默认字号

编辑器和合成服务的默认字幕字号为 50，由 42 增大约 19%。未明确设置样式的新字幕，在画面底部使用较大的默认字号。

已保存的单条字幕样式仍优先：修改默认值不会重写原有字号、位置、文字颜色、背景或时间。自定义标题保留自己的字号。恢复某条字幕的默认位置和字号时使用 50；可选的批量编辑与默认值调整相互独立。

预览和导出继续沿用既有的原画面字体比例规则，包括成片中的等比例缩放。
