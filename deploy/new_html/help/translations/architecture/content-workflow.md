# 内容工作流约定

本文规定图片、视频和音频输出的共同规则。

## 候选版本与选用

生成结果会在指定槽位中创建一个候选版本，例如 `keyframe`、`video` 或 `dialogue_audio:<segment-id>`。创建版本不等于选用版本。选用是明确、幂等的操作，作用范围限定于实体、稳定谱系和槽位。

这种分离可以防止较晚完成的任务替换用户当前选中的结果。

## 稳定谱系

供应商任务执行时，分镜修订可能替换数据库行标识。因此，提交元数据需要同时记录请求实体及其稳定谱系标识。挂载结果时，根据谱系找到当前实体，并记录是否属于迟到挂载。

## 素材绑定

素材绑定保存为项目默认值，并允许镜头级覆盖。任务提交前一刻解析最终生效的绑定。生成任务载荷可以记录已解析的绑定版本以供审计，但可变化的 URL 不能成为唯一可信来源。

## 待更新状态传播

剧本、角色、场景、道具或已选上游版本发生变化时，只为受影响的下游槽位创建待更新事件。这是提示性状态：不会删除输出，也不会自动启动收费生成。

## 结构化剧本修改

AI 辅助编辑产生包含新增、删除和替换的结构化补丁。用户预览并确认后，才写入新的当前剧本版本。被拒绝的补丁不能成为生效内容。
