# 后台分组管理

项目分组与项目是不同实体。创作者视图和管理员视图共用 `project_groups` 记录及 `projects.group_id` 关系。分组重命名后身份不变；删除分组保留项目，但移除分组共享。只有项目所有者能把项目分配到自己拥有的分组。

节点登记分类使用 `comfyui_agents.registry_kind`：`managed` 表示由运营方控制的设备，包括可配置的租用云 GPU；`external` 表示由供应商运营、仅提供使用权限的执行服务。旧记录为空时，暂在本地区域展示并标记为未确认。

分类只属于管理元数据，不改变节点身份、鉴权、启用状态、心跳或任务，也不授予工作流兼容能力。更新接口仅限超级管理员，并记录审计。不能将这个登记标签当成调度或运行授权策略。
