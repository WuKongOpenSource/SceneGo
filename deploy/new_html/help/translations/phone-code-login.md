# 手机验证码登录与注册

在登录页选择“验证码登录 / 注册”，输入手机号，完成安全验证后获取验证码。手机号不必已有账户即可接收登录验证码。输入有效验证码后，系统仅在需要时创建普通账号，并建立与已有用户相同的浏览器会话；该流程不需要单独注册页面或初始密码。

密码登录与明确的密码注册入口仍然保留。验证码创建的账号可以继续使用短信登录，也可通过现有的已验证密码重置流程设置密码。不存在共享密码或默认密码：标准注册流程会对一个密码学随机秘密进行哈希，该秘密不会公开或以明文保留。已有密码、角色与权限不变。

验证码绑定规范化手机号和登录用途，具有有效期且只能使用一次。注册、重置、绑定用途的验证码不能当作登录验证码。验证成功后才创建账号，使用普通注册的相同 DAO 默认值。唯一的已验证手机号索引处理并发创建：复用成功创建的账户，绝不覆盖。已禁用账号仍不能登录。验证失败、短信发送失败、账号或数据库错误都不会签发会话。图形验证、重发冷却与短信每日预算继续有效。

成功请求使用现有 HttpOnly 会话 Cookie，并保留权威账号状态及会话版本检查、最近登录和在线状态更新、每日奖励流程及同源跳转目标校验。新账号不会自动获得管理员权限。仅发送验证码不会创建用户或授予奖励，无需数据库结构迁移或批量注册历史手机号。
