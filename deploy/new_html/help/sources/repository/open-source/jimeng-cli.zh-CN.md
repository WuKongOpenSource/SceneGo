# 即梦独立视频通道

产品名为 **Jimeng·Seedance 2.0 · 真人视频模型**，实际通过官方 CLI 执行
`seedance2.0mini` 的 `multimodal2video`（全能参考）。它不是 Ark API，
也不会降级到标准模型、其他模型或其他账号。真人素材仍须取得授权并通过供应商审核。

本模型仅限处于正常状态的管理员（`admin`）和超级管理员（`super_admin`）使用。
普通用户的模型列表显示不可用及权限说明；服务器在预检和首次付费提交前读取真实账号角色，
不能通过修改前端、伪造角色或模型白名单绕过。排队期间失去权限的任务不会提交，预留点数退回。
已经提交供应商的任务继续查询和保存原成片，不会因角色变化丢弃结果或重复生成。
独立账号配置和授权状态管理仍仅限超级管理员；使用权限不等于账号配置权限。

## 参数和点数

- 720P；固定比例 1:1、3:4、16:9、4:3、9:16、21:9。
- 生成 4–15 秒整数视频；短脚本按至少 4 秒提交，小数向上取整。
  只调整生成请求，不改写剧本、配音或剪辑时间轴。
- 图片最多 9 张、视频最多 3 段、音频最多 3 段，总数最多 12；不能仅用音频。
  每段视频和音频均为 2–15 秒，两种媒体各自累计不超过 15 秒。
- 服务器读取已授权文件记录所指向的原文件，校验真实格式、时长和 SHA-256。
  不把缩略图传给供应商，不自动裁剪台词，不接受任意外部 URL 或服务器路径。
- 平台创作点数按 Seedance 2.0 标准模型同生成时长、分辨率和参考视频时长报价的 **1 倍**计费；15 秒、720P、无参考视频时为 **315 点**。
  服务器预留后才入队，成功结算、已确认失败退回；即梦账号点数是另一套单位。
- 不提供未经验证的随机种子、声音开关、水印开关和取消接口。

## 运行环境与独立授权

公开源码不包含 CLI 二进制、OAuth 状态、账号、供应商结果或生产部署脚本。
管理员从 [官方 CLI 分发入口](https://jimeng.jianying.com/cli) 获取并审查安装方式，
自行安装和固定已验证版本的 SHA-256。不能执行来源不明的安装脚本。
开发核验使用官方 CLI 1.4.18 的离线帮助；OAuth 返回格式和新账号实际生成必须另行现场验收。

运行要求是 POSIX 环境，一个专用的非 root OS 用户，以及其独占、持久化的 HOME。
CLI 可执行文件位于 HOME 之外且不可由该用户修改。HOME 权限为 0700，不位于任何 Web
静态目录或用户文件目录。应用可以使用相同专用用户，或由 root 应用以明确 UID/GID
降权执行 CLI。调用采用独立环境和参数数组，不使用 shell、不继承应用密钥或代理。

先以该专用 OS 用户在此 HOME 中完成官方设备授权，再创建一个**新的专用会话**。
不要复用别的产品的 HOME、OAuth、默认会话（0）或按会话名称推断 ID。
授权和新会话创建后，管理员核对 `user_credit` 返回账号 ID，核实新会话的真实数字 ID。
不要在网页、源码、任务数据或日志中粘贴 access token、refresh token 或设备码。

在专用 HOME 内创建权限 0600 的 `.ovideo-jimeng-state.json`，只记录已核实的绑定标识：

```json
{
  "account_id": "REPLACE_WITH_VERIFIED_NUMERIC_ACCOUNT_ID",
  "session_id": "REPLACE_WITH_NEW_NONZERO_NUMERIC_SESSION_ID",
  "state_id": "REPLACE_WITH_NEW_RANDOM_STATE_ID"
}
```

`state_id` 使用新生成、长度 16–80 的字母数字、下划线或连字符标识；它绑定整个持久化
CLI 状态。备份和恢复时必须连同 HOME 中的 OAuth 和任务数据库一起保留，不能只复制这个
标识文件。任务数据库丢失时，既有任务可能无法查询；只能人工核查，不能重新付费提交。

应用环境变量如下，默认不开启：

| 变量 | 要求 |
| --- | --- |
| `JIMENG_CLI_ENABLED` | 独立授权和环境核验完成后设为 `true` |
| `JIMENG_CLI_BIN` | 已验证 CLI 的绝对路径，不得位于可写 HOME 中 |
| `JIMENG_CLI_SHA256` | 安装文件实际 SHA-256，升级后重新核验 |
| `JIMENG_CLI_HOME` | 专用用户独占的持久化 HOME 绝对路径 |
| `JIMENG_CLI_UID`、`JIMENG_CLI_GID` | 专用非 root 用户和组的数字 ID |

先应用规范迁移清单中的 `db_migration_jimeng_jobs.sql`，再启动应用。
后台「厂商 API Key 与 Endpoint」页面有独立「即梦」账号卡；超级管理员可刷新账号、
专用会话和即梦点数状态。未完成授权时模型保持不可用，不能假装已接通。

## 恢复与验收

每次付费命令前必须持久化提交意图；任务号返回后立即保存。
`submitting` 阶段中断或响应中没有可信任务号会进入 `review_required`，保留冻结点数、
停止自动提交，并阻止此账号继续提交其他付费任务。管理员核实供应商历史后再人工处理。
不能通过重启、清空本地状态、换账号或点击重做绕过核查。

拿到任务号后只查询原任务。查询、下载或入库暂时失败可以继续恢复原任务，不能新建
供应商任务。成功文件必须在当前任务私有目录内，经过真实媒体探测和内容哈希校验；
文件记录、镜头归属、素材库保存和点数结算完成后，界面才显示完成。
片段时长以真实成片探测为准，不使用 CLI 的展示元数据替代。

生产启用前须完成本产品账号的设备授权与会话绑定核验。付费验收另行确认账号、
原素材、时长、分辨率、平台预计点数和供应商点数；一次授权只执行约定的一次测试。
仅通过离线和模拟测试，不能宣称已经验证真实供应商生成或下载。
