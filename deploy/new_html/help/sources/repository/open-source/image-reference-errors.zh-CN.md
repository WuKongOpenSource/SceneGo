# 分镜参考素材失效处理

画面生成使用当前镜头“实际提交参考图片”中的明确选择，不会自动把失效图片忽略或换成另一张图片。

如果参考图片显示“素材不可用，请重新选择”：

1. 检查网络并刷新页面；图片加载失败不一定代表文件被删除。
2. 若原图已删除、不可读取或当前账号没有访问权限，从当前镜头参考列表移除失效引用。
3. 在“项目素材”中选择需要的有效原图，并核对角色、场景、道具及图片版本。
4. 再次点击生成。单张和批量生成都会校验实际提交的参考素材；纯文生图不会检查未提交的参考图。

校验本身不创建生成任务、不调用模型、不扣除创作点数。错误提示不会返回服务器路径，也不会区分其他用户的私有文件与不存在的文件。生成接口仍保留权限校验，防止校验后素材被删除或权限发生变化。

素材库的新版本不会自动覆盖其他镜头的手动选择。仅需修复部分引用时，应逐条确认同一素材与版本对应关系，保留有效引用、提示词和历史生成结果。
