# Natural-week release history

Source revision: `d3a67099e44bec9a0d487b5e90cc85c28da4fc8e`.

The changelog dialog and public updates page group records by calendar weeks,
Monday through Sunday. The current week uses the Asia/Shanghai calendar and is
expanded by default; older weeks are collapsed and can be opened with a mouse or
keyboard. An empty current week remains visible without relabeling older updates
as current. Open pages refresh the calendar at midnight and when focus returns.

All existing release records and version numbers are preserved. The metadata
period describes the full available history, not a mandatory rolling seven-day
window; its validation still enforces chronological, unique, valid dates and
complete coverage. Add new records without removing previous weeks.

This synchronization changes shared presentation and regression coverage only.
It does not modify production data, enable local processing, or deploy a website.
