# 内容页签样式

内容页签统一参考“开始放大 / 放大历史”：白色底栏、灰色未选文字、紫色选中文字与 2px 底部横线，不使用胶囊背景、圆角外框或投影。

主应用、登录页、画布共用 `deploy/static/css/tab-navigation.css`。页签容器使用 `ui-tabs`，按钮使用 `ui-tab`，选中状态由原有 `aria-selected`、`aria-pressed` 或 `aria-checked` 驱动。登录页保留原有 `.active` 选择器及验证码流程。普通页签高 48px，紧凑工具栏可用 `ui-tabs--compact`（40px），视觉规则一致。

已覆盖成品分享/审阅、成品与素材范围、项目/分集分类、图片放大、声音工作台及音频资产、设计分类、剧本工作模式、项目素材选择、图片编辑、分镜工具/插入、视频后处理、管理功能/API 分类，以及画布历史与涂鸦工作区。

窄屏保持单行横向滚动，不挤压或折行标签。键盘焦点使用文字虚线提示，与选中横线区分；暗色画布使用同一结构和适配的紫色对比度。

侧栏导航、流程进度步骤、状态标记、模型/生成参数选择和操作按钮不属于内容页签，保留原有样式。此修改不改变 API、持久化、任务、点数或音视频生成逻辑。

回归检查：分享和审阅反复切换时仅选中项带横线，反馈保持不丢失、不重复请求；登录切换仍显示对应输入框；窄屏横向滚动可访问全部页签；Tab 键可见焦点且 Enter/Space 可切换；画布浅色/暗色均清晰。
