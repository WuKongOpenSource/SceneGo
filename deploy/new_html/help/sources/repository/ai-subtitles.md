# AI 字幕

在「生成短片 → 优化合成」的时间线工具栏点击「AI 字幕」。

1. 选择识别来源。默认跟随当前合成的「视频原声 / 参考配音」模式，也可以单独选择；音乐和音效轨不用于对白识别。
2. 点击「开始识别」。系统按原素材裁剪范围分段提取音频，保留真实说话时间，显示逐段进度。没有音轨或静音的片段不会提交识别。
3. 检查预览，再点击「加入字幕轨道」。默认保留已有字幕，只补空白时段。可以选择更新旧自动字幕（保留手写字幕），或确认后替换全部字幕。
4. 加入后可编辑文字、拖动或裁剪字幕、调整样式；使用现有时间线自动保存、撤销和成片字幕合成流程。

识别失败、取消或关闭窗口不会修改已有字幕。识别期间视频或配音时间线变化时，旧结果不可应用，需要重新识别。自动字幕仍需人工校对；方言、多人重叠对白和背景音乐可能影响准确率。取消会停止后续片段；已提交到识别服务的当前片段可能继续处理并产生供应商费用。

## 管理员配置

AI 字幕使用本部署已有的工作流文本通道账户，由兼容接口提供 `whisper-1` 语音转录。先确认该账户支持 `/v1/audio/transcriptions`、`verbose_json` 和逐词时间戳，再设置 `SUBTITLE_TRANSCRIPTION_ENGINE=whisper` 并重启应用。未配置时入口会明确显示不可用原因，不会自动切换到其他模型或账户。

服务需要 `ffmpeg`、`ffprobe`。每个请求最多识别 60 秒，每位用户同一时间只处理一个请求；每个应用进程最多并行处理两个请求。前端按片段串行识别，单次预览最多 1 小时、200 段。多进程部署的并发上限按进程累加，管理员应按供应商限额控制进程数。

输入必须是用户有权访问且已登记的项目素材，并通过现有文件归属、回收站和受限素材目录校验；原文件读取遵循现有音视频大小上限（默认 20 MiB）。任意本地路径、未登记的远程地址、内联数据和临时浏览器地址不予接受。逐词时间点缺失、越界或乱序会报错，不会用估算时间替代。
