# 公开测试与运行时边界

## 保留相同行为，不按失败结果筛选测试

公开版必须保留在线供应商、账户、项目、计费、媒体与安全相关的回归。完整应用额外拥有私有节点能力；其实现和测试不进入公开源码，但仍在完整开发仓库执行。

最低公开回归清单是必须保留的覆盖，不是可发布测试的全部列表。其他测试的导入错误、失败和私有耦合必须逐项处理，不能通过跳过、吞掉 ImportError 或保留私有运行依赖来获得通过。

## 在线供应商执行契约

`deploy/tests/provider_execution_contract.py` 汇集共享断言，具体测试类提供 Worker 类型和任务类型：

- `test_worker_minimax_tts.py`：音频生成、试听回写、错误反馈、输出大小限制。
- `test_worker_external_api_non_retryable.py`：鉴权与业务拒绝不重试、网络错误保留既有重试、保存失败不能伪装成功、元数据回写、受限下载、参考媒体处理及拒绝后的退款。
- `test_worker_file_url_resolution.py`：参考图只能经过统一的受权媒体解析服务。
- `test_dashscope_wiring_e2e.py`：模型扩展参数不能被请求模型或 Worker 丢弃。虽然保留历史文件名，此测试是模拟边界的参数传递回归，不是真实供应商端到端生成。

这四个文件使用公开在线 Worker；完整应用另由 `test_private_provider_execution.py` 实例化同一套契约，使用私有 Worker 和原任务模型，并检查完整入口仍引用共享请求模型及 CORS 解析器。私有组合测试被发行规则明确排除，公共断言及其辅助文件必须保留。

测试不启动 Worker 循环、不调用供应商。真实队列消费、持久化、外部接口及用户交互需要对应层级的验收，不能只凭模拟测试推断。

## 取消、提交和退款

`deploy/tests/task_cancellation_contract.py` 共享以下约束：排队任务取消后不能重新领取或复活；准备阶段取消可以阻止提交；已提交任务和旧运行记录不能退款；退款失败的标记可以跨队列实例恢复；重复取消依赖账本幂等，不能重复返还余额；取消与提交的原子竞态只能由一方获胜。

`test_task_cancellation.py` 测试公开队列和 Worker 提交；`test_private_task_cancellation.py` 测试私有队列和 Agent 领取。模拟 Redis 在夹具或 finally 中关闭，即使用例断言失败也须释放。

Agent 原子领取实现在 `core/agent_dispatch_guard.py`，只由私有 Agent 路由引用；公开的 `core/task_dispatch_guard.py` 保留通用提交、取消和退款保护，不再包含节点领取实现。历史任务所有权字段仍参与拒绝错误退款的判定，不能在剥离执行能力时一并删除。

`task_terminal_contract.py` 进一步共用预分配任务 ID、取消后的迟到结果及不存在任务的终态保护：不能重新入队、发布完成事件或触发结算/退款。两种队列保留各自的处理中队列键，不为测试统一存储协议。公开版另验证最终失败清理与退款；完整应用的历史 JSON 队列、本地名额及通道迁移断言仍在 `test_private_task_terminal_guards.py` 执行。

## 权限、计费与每日配额

`admin_role_contract.py` 同时验证公开管理服务与完整应用兼容路由的权限判断。`task_billing_contract.py` 同时验证两种任务提交服务：预留点数先于入队、余额不足返回 402、入队失败释放点数，以及原有计费元数据的保留。

两个入口的可选内置账户配置共用 `admin_bootstrap_service.load_builtin_users`，并由 `builtin_admin_contract.py` 运行相同断言。显式密码无效时禁用内置登录，不回退到开发密码；生产环境标识忽略首尾空格和大小写，不能开启开发默认密码。合法显式密码、开发环境主动启用及无配置时禁用的行为不变。此加载器不修改数据库账户、角色、会话或一次性角色初始化标记。

公开任务模型保留其浅拷贝语义，完整任务模型保留其原字典引用语义。公共断言检查内容相等，各组合另外检查自身的引用契约，不能为统一测试而改变调用者的数据所有权。

海螺在线任务共用 `online_task_quota_service.py` 的每日策略和 `core/daily_task_quota.py` 的 Redis 原子操作：

- `minimax_i2v` 与 `minimax_morph` 共用全平台每天 3 次提交限额，不是按账户分别计数。
- 以上海自然日计数，数据库查询边界仍为无时区 UTC，Redis key 和次日加一小时的过期规则保持不变。
- 先读取持久化任务 ID，再预占名额，再预留点数，最后入队。历史 ID 去重补入 Redis；重复任务 ID 保持原有幂等行为。
- 入队失败或点数不足时释放本次名额；退款失败不能阻断配额清理；数据库种子查询失败不能释放尚未预占的名额。

`daily_quota_contract.py` 对两种队列执行相同 Lua 并发与重启补种测试；`test_online_daily_quota.py` 验证跨上海午夜的日期边界。完整应用的本地节点与图片放大队列仍由私有测试单独覆盖，不改变其名额规则。

## 语音提交、参考音频与媒体读取

`tts_enqueue_contract.py` 保留语音提交的任务 ID、分镜谱系、角色声音绑定、未配置供应商时不入队等断言。公开应用与私有兼容路由分别提供严格签名的服务替身；公开应用原有的登录、对象访问、配置缺失和服务生命周期测试继续执行。

`seedance_audio_contract.py` 共用真实 WAV 夹具及“参考音频超限时不扣点、不入队”的断言。两种提交服务都执行这一断言；公开回归不再通过动态导入私有任务服务完成验证。音频裁剪的原字节保留与时长测试继续保留。

通用视频 HTTP 客户端测试不依赖本地节点文件服务；节点源文件读取的原有断言保留在 `test_private_video_source.py`。这些明确命名的私有组合测试仅不进入公开发行，仍须在完整开发仓库通过。

## 健康检查与只读停滞诊断

`runtime_health_contract.py` 对公开入口和完整应用使用相同断言：数据库不可用、在线任务等待或处理超时、数据库仍有活动任务但 Redis 两个在线队列均为空，都不能返回整体健康。`test_cluster_status_health.py` 使用公开健康路由；`test_private_cluster_status_health.py` 保留完整应用的处理节点与本地队列测试，并实例化同一共享契约。

两种健康路由共用 `runtime_health_service.online_queue_health_status`。数据库只读取活动任务的分组计数与最早时间，不读取提示词或媒体内容，不协调、重试、取消任务或修改点数。SQL 与 Redis 不是同一事务快照；数据库仍显示排队、Redis 已进入处理队列的正常交接不能被当作任务丢失。`inconsistent` 是需复核的诊断结果，不是允许自动重新生成的指令。

等待与处理阈值分别由 `HEALTH_QUEUE_MAX_AGE_SECONDS` 和 `HEALTH_PROCESSING_MAX_AGE_SECONDS` 配置，默认 3600 与 7200 秒。只在超过阈值时报告 `stalled`。公开管理接口保持 `online_queue` 的原有字段；完整应用在 `api_tasks` 增加 `status`。匿名 `/health` 仍只有整体状态，公开管理接口也不回传数据库异常原文。健康响应仍使用 HTTP 200，监控必须读取 JSON 状态，不能仅检查 HTTP 状态码。

## 私有测试的逐项归属

`generation_route_contract.py` 让公开路由与完整应用都验证：无权访问目标作用域时不得入队；海螺未指定时长时使用 6 秒；不支持的时长/清晰度组合在入队前拒绝；Seedance Mini/Fast 的清晰度同时受 HTTP 模型校验与内部调用保护。参考素材的 URL、文件 ID、首尾帧分别经过实际授权服务；跨项目或无权限素材不能提交，合法素材按原始引用传入，不更换图片字节或修改请求对象。`test_private_generation_route_contract.py` 只负责私有路由装配；原工作流准备和 H3 别名测试分别完整保留在对应的 `test_private_*` 文件中。

`video_crop_contract.py` 共用已登记源文件的 ACL、拒绝未知或无权源文件、裁剪结果与文件记录对应、原视频不变、FFmpeg 缺失/失败不得入库及临时输出清理断言。公开适配不加载节点协议。完整应用原有数据库节点源、直接节点回退、兼容路径及默认项目/版本行为仍在 `test_private_video_crop_service.py` 全部执行。公开裁剪只接受已登记、受权且位于允许媒体根目录内的源，继承源文件版本；这些安全边界不能为了模拟旧路径回退而放宽。真实 FFmpeg 的有声/无声输出回归继续单独执行。

逐项审查后的工作流降级、角度工作流、变形占位符、潜空间尺寸和工作流完整性测试均仅验证私有工作流配置、图节点映射、模型路径或注入策略，不进入公开候选，但完整仓库中保持原样执行。旧裁剪服务包含私有节点读取和回退，公开候选仅保留独立的公开裁剪实现与上述通用契约。此名单不适用于名称相似但尚未审查的其他文件。

图片放大的迁移校验、计价和界面契约仍留在 `test_image_upscale_feature.py`；仅 Agent 完成回调的两个断言移入 `test_private_image_upscale_outputs.py`，在完整应用回归中继续执行。这种拆分不证明公开版拥有本地图片放大能力，公开前端的可用能力仍需单独审查。

工作流目录构建与同步工具处理私有工作流、配置映射及模板数据库，不是通用媒体或数据库版本迁移能力。发行规则逐项排除 `build_workflow_catalog.py`、`sync_workflow_templates_from_catalog.py` 及各自的实现测试；开发仓库不删除这些文件，完整回归继续执行。不能据此排除其他混合测试中的权限、计费或在线供应商断言。

## 独立源码验证

源码内容审查与构建产物审查是两个不同门禁。线上专用的 HTML 入口、混合路由 JSON、完整平台路由门禁和私有桥接前端测试不进入公开源码；它们仍在完整仓库验证。通用 AST 导入调用检查提取到 `scripts/source_contract_utils.py`，公开测试直接依赖该无运行时目录的帮助函数。公开界面样式检查使用 `public-entry/index.html`，私有托管入口的域名和样式检查另保留；通用媒体测试直接执行公开媒体服务，完整服务的六项原断言保持不变。

测试中的普通示例域名使用保留的 `.test` 域名，不指向在线产品。仅已审查的两个公开边界负向测试允许包含它们所拒绝的字面量特征，这不是整个测试目录的扫描豁免，也不允许借此放入私有实现。门禁自身验证：原路径可以容纳负向样例，把同样内容复制到其他测试路径仍会被拒绝。文件、目录、清单和发布完成要求对这两个文件照常生效，内容变更仍需人工审查。

两种入口共用的旧 Bearer 转 Cookie 中间件必须尊重接口已签发或清除的会话 Cookie，不能在改名后覆盖稳定 ID 的新 Cookie，也不能在退出后重新写回旧凭证。`test_session_cookie.py` 同时覆盖开发/生产 Cookie、新签发/清除/无关 Cookie；账号改名的真实数据库 HTTP 回归分别使用旧 Cookie 和旧 Bearer。兼容迁移成功标记仍保留，拒绝无效凭证及同源限制不放宽。

全量公开测试还必须覆盖管理员账号、版本页面、媒体缓存和迁移账本。混合文件中的容器入口、自动部署和长耗时节点回收配置断言拆到逐项列出的私有测试；原断言仍在完整平台执行。公共迁移顺序、镜像 SQL 一致性、已执行迁移校验和及重复运行保护不删除。版本页测试直接验证公开入口实际注册的 37 条前端路由，完整入口的抽取检查另保留。媒体缓存测试中的“private”表示用户私有素材，不代表节点能力；公开 HTTP 回归覆盖 `/storage/`、`/uploads/` 的成功与错误响应，均须覆盖为禁止共享缓存。

工作流导入测试中的通用管理页面资源版本校验留在公开测试中，私有模板导入、图修复和工作流 UI 断言单独保留。模板 DAO、已验证图修复工具、SeedVR2/InfiniteTalk 视频增强图、节点打印交付与退款测试均只服务私有执行能力；对应实现和整套测试不进入公开候选，不改写其开发仓库行为。公开的图像放大计价和媒体契约仍保留，不能据此声称公开版拥有节点执行能力。

公开管理端补齐 `/api/admin/users/{user_id}/username`，使用现有稳定身份改名服务，仅超级管理员可调用；自身改名时将旧用户名会话更新为稳定 ID 的 HttpOnly Cookie。测试同时核对真实数据库中的项目归属、审计操作者/目标 ID、改名后的会话、重复改名无副作用及普通账户/管理员无权修改。公共列表将无时区的历史登录时间按 UTC 输出，并保留毫秒字段；创建账户未返回持久化 ID 时返回 503，不记录成功审计。完整应用原管理路由的断言保留在 `test_private_admin_user_routes.py`，不反向导入到公开运行时。

`test_public_runtime_source_isolation.py` 从公开入口的导入闭包及明确列出的测试辅助文件构建临时源码树。共享数据库健康帮助函数与测试契约随之保留；公开 HTTP 健康端点使用更小的响应格式，其测试不应反向依赖完整入口。

独立树再次执行最低公开回归，检查各文件确实产生测试结果、没有失败或跳过、没有引入私有 Worker、任务队列或 Agent 领取模块，且运行前后源码哈希不变。数据库只能来自专用测试配置。

此临时树不是发行包。完整测试收集、全量测试、前端公开构建、独立安装、许可证、历史、隐私及发布清单仍是单独的发行门禁。
