# 项目管理

项目管理页面用于查看和进入创作项目。用户可以从开始新作品创建新项目，也可以从我的作品和最近作品中继续已有项目。

![项目管理操作示意图](/assets/help/media/manual-rId9.webp)

图 2 项目管理与最近作品入口

## 我的作品

我的作品页面展示当前账号创建或参与的项目。项目卡片通常包含项目名称、分集数量、项目简介、成员数量和更新时间。

1. 点击左侧导航中的我的作品。

2. 在项目列表中查找目标项目。

3. 点击项目卡片进入项目分集页面。

## 项目筛选和排序

项目页面支持全部项目和已归档项目筛选，并提供最近更新、创建时间、名称等排序方式。
