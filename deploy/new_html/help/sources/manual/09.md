# 故事板

故事板页面用于为分镜生成画面。用户可以逐镜头生成，也可以选择多个镜头批量生成。生成前应检查角色参考图、场景素材、道具素材和图像提示词。

## 生成分镜图

1. 进入故事板页面。

2. 在左侧选择需要生成的分镜。

3. 检查图像提示词和参考素材。

4. 选择生成模型、画面比例和分辨率。

5. 点击生成，等待任务完成。

## 参考素材

故事板支持角色、场景、姿势、道具和效果等参考素材。为了保持角色一致性，建议先完成角色身份参考图，再批量生成后续镜头。
