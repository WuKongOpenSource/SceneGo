# 个人中心和创作点数

个人中心用于管理账号信息、通知邮箱、密码安全、最近项目和创作点数。创作点数用于 AI 生成任务，任务提交时可能先冻结预估点数，成功后结算为消耗，失败则退还。

## 查看点数

1. 点击顶部创作点数入口。

2. 查看可用点数、账户点数、赠送点数和冻结点数。

3. 进入创作点数流水，核对冻结、退还和消耗记录。

![个人中心和创作点数操作示意图](/assets/help/media/manual-rId61.webp)

## 通知设置

1. 进入个人中心。

2. 填写通知邮箱并完成验证。

3. 选择任务完成、任务失败、创作点数提醒、分享与协作等通知类型。

4. 点击保存通知设置。

## 账号安全

用户可以在个人中心修改登录密码。修改密码前应确认当前密码正确，并使用符合安全要求的新密码。
