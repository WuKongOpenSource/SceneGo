# 创建项目与分集

新作品创建流程用于建立创作项目。建议项目名称使用正式作品名，项目简介说明故事类型、主要人物、核心冲突和预期风格。

![创建项目与分集操作示意图](/assets/help/media/manual-rId10.webp)

![创建项目与分集操作示意图](/assets/help/media/manual-rId11.webp)

图 3 新建项目与分集入口

## 创建项目

1. 点击开始新作品或新建项目。

2. 填写项目名称。

3. 填写项目简介，说明故事背景、人物关系和创作方向。

4. 确认创建后进入项目页面。

![创建项目与分集操作示意图](/assets/help/media/manual-rId12.webp)

## 创建分集

1. 在项目页面点击新建分集。

2. 填写分集标题。

3. 进入分集工作流页面，按照四步流程开始制作。

![创建项目与分集操作示意图](/assets/help/media/manual-rId13.webp)
