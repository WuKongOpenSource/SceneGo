# 排画面和声音

排画面和声音是分集制作的第三步。该步骤包含配音制作、音乐生成、故事板图像生成和镜头时间关系检查。

![排画面和声音操作示意图](/assets/help/media/manual-rId32.webp)

图 7 配音制作和音乐生成入口

## 配音制作

1. 进入排画面和声音页面。

2. 选择配音制作标签。

3. 点击同步到故事板，确保文本和镜头对应。

4. 选择角色、情绪、语速和音调。

5. 点击生成配音，生成后检查音频时长是否超过设计时长。

![排画面和声音操作示意图](/assets/help/media/manual-rId33.webp)

![排画面和声音操作示意图](/assets/help/media/manual-rId34.webp)

## 音乐生成

1. 切换到音乐生成标签。

2. 输入音乐风格、情绪和时长说明。

3. 选择纯音乐或主题歌方式。

4. 生成后在音频素材列表中检查结果。

![排画面和声音操作示意图](/assets/help/media/manual-rId35.webp)

## 时长检查

当音频实际时长超过镜头设计时长时，系统会显示时长警告。此时可缩短台词、调整语速，或在后续视频和成片阶段调整镜头时长。
