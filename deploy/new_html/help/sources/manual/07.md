# 可用素材与素材库

可用素材页面用于检查每个镜头关联的人物、场景和道具。素材库用于集中管理本集素材和全部素材，支持搜索、上传、收藏、批量下载和可见范围设置。

## 素材绑定

1. 进入可用素材页面。

2. 在镜头列表中选择目标镜头。

3. 检查该镜头已关联的人物、场景和道具。

4. 对缺失素材执行 AI 生图或上传素材。

## 素材库搜索

1. 进入我的素材。

2. 在搜索框输入素材名称关键词。

3. 查看过滤后的图片、视频或音频素材。

4. 点击收藏按钮可将常用素材加入收藏筛选。

## 可见范围

素材默认可设为私有。对组可见需要切换到组织环境后使用。发布前应确认素材版权、授权和可见范围。
