# 定角色和场景

定角色和场景是分集制作的第二步。系统按人物、场景、道具三个维度管理视觉设计。用户可以同步已有设计，也可以手动创建新的角色、场景或道具。



![定角色和场景操作示意图](/assets/help/media/manual-rId19.webp)

图 5 人物、场景、道具设计页面

## 创建人物

1. 点击人物标签。

2. 点击手动创建。

3. 填写人物名称和外观描述，包括年龄、发型、服装、气质和关键特征。

4. 保存后可使用 AI 生图、上传、角度、高清放大和去水印等功能补充素材。

## 创建场景

1. 点击场景标签。

2. 填写场景名称和空间描述。

3. 说明时间、地点、光线、氛围和关键物件。

4. 保存后可为镜头绑定该场景素材。

![定角色和场景操作示意图](/assets/help/media/manual-rId25.webp)

## 创建道具

1. 点击道具标签。

2. 填写道具名称和视觉描述。

3. 说明道具在剧情中的用途。

4. 保存后可在后续分镜中引用。
