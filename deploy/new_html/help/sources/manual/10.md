# 生成短片

生成短片是分集制作的第四步。系统会将分镜导入视频工作区，并按镜头生成视频任务。用户可以为每个任务选择模型、时长、提示词、媒体输入和输出参数。

## 同步分镜图

1. 进入生成短片页面。

2. 点击同步最新分镜图，将故事板生成结果导入视频工作区。

3. 检查每个镜头是否已有首帧图片。

4. 如有分镜图更新提示，应确认是否重新同步。

![生成短片操作示意图](/assets/help/media/manual-rId46.webp)

## 执行视频任务

1. 选择目标镜头任务。

2. 选择视频生成模型，例如 Seedance、Wan、Kling、Vidu 等。

3. 填写或检查动作说明和视频提示词。

4. 设置分辨率、画面比例、时长和水印等参数。

5. 点击执行生成任务，等待状态变为完成。
