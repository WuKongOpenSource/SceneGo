# 写故事

写故事是分集制作的第一步。用户可以输入故事正文或故事梗概，系统根据内容生成分段、视频脚本和分镜设计。该步骤决定后续镜头数量、画面内容和素材需求。

## 输入故事内容

1. 进入分集后点击写故事。

2. 选择快速版、写作版或视频反推模式。

3. 在故事输入区填写故事文本。

4. 检查故事是否包含主要人物、地点、事件和情绪走向。

![写故事操作示意图](/assets/help/media/manual-rId16.webp)

## 生成脚本和分镜

1. 点击按三步生成。

2. 等待系统拆分故事段落。

3. 等待系统生成视频脚本。

4. 等待系统生成分镜设计。

5. 生成完成后检查分镜数量、镜头描述和视觉风格是否符合预期。

## 文件操作

写故事页面支持创建空白文件、上传文件和下载 JSON 备份。建议在关键版本生成后下载备份，以便恢复或对比。
