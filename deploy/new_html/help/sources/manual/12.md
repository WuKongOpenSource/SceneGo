# 专业画布

专业画布是更自由的节点式创作工作区，适合有经验的用户组合文生图、文生视频、首尾帧、声音工厂和 AI 创意助手等能力。

## 基础工作流

1. 点击更多功能中的专业画布。

2. 点击一键创建基础工作流。

3. 根据需要选择文字生图、文生视频或首尾帧节点。

4. 填写提示词并上传参考素材。

5. 确认预计消耗后生成。

## 使用建议

专业画布更适合探索单个镜头或补充素材。正式分集制作建议优先使用四步工作流，以确保脚本、素材、镜头和成片历史能够保持关联。
