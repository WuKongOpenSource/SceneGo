# 登录注册

用户进入创剧登录页面后，可以使用已注册手机号和密码登录系统。登录成功后系统进入创作工作台，左侧展示开始新作品、我的作品、成片与分享等入口。

![登录注册操作示意图](/assets/help/media/manual-rId8.webp)

图 1 登录页面及账号密码输入位置

## 登录操作

1. 打开创剧登录地址：https://tv.ostory.ai/login。

2. 在手机号输入框中输入账号手机号。

3. 在密码输入框中输入账户密码。

4. 点击登录按钮，进入系统工作台。

## 注意事项

如登录失败，请检查手机号、密码和网络状态。若账号长期未使用或密码遗忘，应按系统提供的找回密码或联系管理员流程处理。
