# 优化合成与成品导出

视频生成完成后，可进入优化合成页面进行高清放大、智能补帧、对口型等处理，也可以进入导出成片页面合成最终成品。

## 导出到美化

1. 在视频工作区选择已完成的视频片段。

2. 点击导出到美化。

3. 在优化合成页面确认视频段和音频段数量。

4. 选择需要的处理能力后提交任务。

![优化合成与成品导出操作示意图](/assets/help/media/manual-rId52.webp)

## 合成成品

1. 进入导出成片页面。

2. 点击合成成品。

3. 确认将合成的镜头数量。

4. 点击开始合成。

5. 合成完成后可在成品历史中查看、下载或分享。

![优化合成与成品导出操作示意图](/assets/help/media/manual-rId53.webp)

## 分享和下载

下载用于保存本地成片。分享可能生成外部审阅链接，发布前应确认是否允许对外访问。
