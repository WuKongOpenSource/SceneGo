# 第三方许可与核验附件

本页收录开源文档中的许可声明、许可证正文、作者归属及依赖核验记录。中文导读帮助理解用途；权利人原始条款、版权姓名、哈希和结构化字段保持原样，不能用译文替代法律原文。

## 如何阅读

- **许可声明**：部分发行包没有单独许可证文件，附件保留其 README 中的许可声明；这不同于重新授予许可。
- **Apache 2.0 正文及上游许可证**：保留原始授权、再分发、专利、免责和责任限制条款。按原文核对通知和归属义务，不因有中文说明而免除。
- **npm 依赖许可**：包括 esbuild、其 Go 相关归属与专利说明、Rollup、saxes 和 dlv 的证据。不同包不能相互套用许可。
- **构建与版本证据**：三个 JSON 附件记录精确版本、来源、哈希、逐项核对和待确认事项，不是整个项目的完整软件物料清单，也不是全平台发行批准。

## 适用边界

这些附件是原开源文档收集时的证据；更新依赖后必须重新核验，不应仅因文件仍在就认定新版本已获许可审查。安装、使用和再分发前，请结合对应包的完整原文及项目许可判断适用义务。

以下逐项保留全部原始技术与许可附件，供站内阅读；不会下载或执行其中引用的程序。
