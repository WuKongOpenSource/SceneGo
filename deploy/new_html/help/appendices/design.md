# 设计参考图与组件附件

开源文档的设计参考目录包含界面截图与两份组件脚本。这里将截图作为图文参考展示，脚本作为可阅读的源码附件保留，不在帮助中心执行。

## 图片占位组件

`image-slot.js` 定义可填充图片的占位组件。使用时需提供唯一的 `id`；`shape` 控制矩形、圆角、圆形或胶囊形状，`radius` 控制圆角，`mask` 指定裁剪路径，`fit` 可用 `cover` 或 `contain`，`src` 为初始图片。用户拖入图片后，可平移、缩放和重新裁切；支持环境会把状态写入同目录的 `.image-slots.state.json`，普通网页环境为只读。

`placeholder` 是空状态说明，`credit` 与 `credit-href` 是归属文字和链接。使用 Unsplash 图片时必须提供可见归属，不应被覆盖层遮挡。组件占据父容器尺寸；未限定高度时使用默认比例，浮动或收缩布局中应明确给出尺寸。

## 设计预览辅助组件

`support.js` 是设计预览的辅助实现，不是主站业务接口。保留它是为了完整收录文档目录中的技术附件，不代表帮助页面开放设计编辑、文件写入、远程控制或执行脚本。
