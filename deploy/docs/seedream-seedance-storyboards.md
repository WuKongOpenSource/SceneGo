# Seedream 分镜原图与 Seedance 视频对接

## 适用范围与官方依据

图片模型名称是 **Seedream 5.0 Pro**，视频模型名称是 **Seedance**。Pro 的正式模型 ID 为 `doubao-seedream-5-0-pro-260628`，不能用一个不存在的“Seedance 5.0 Pro”图片模型替代。

依据截至 2026-09-09 查阅的火山方舟文档：

- [Seedream 5.0 Pro 教程](https://www.volcengine.com/docs/82379/2582774?lang=zh)：模型 ID、接口及使用方式。
- [Seedance 便利创作含肖像视频](https://www.volcengine.com/docs/82379/2608626?lang=zh)：Seedance 2.5 / 2.0 系列的肖像参考输入范围、账号与有效期约束。

对于包含人像的图片，官方说明允许同一方舟账号近 30 天内由 Seedream 5.0 Lite/Pro **纯文生图**生成的原始产物进入相应受信输入范围。此项图片能力的官方起始日期为 2026-04-16。图生图、跨平台、跨账号、超期，以及压缩或编辑后的文件不在这项原图范围内。非人像素材不受这项人像来源规则限制，但仍需遵守模型的一般输入要求。

受信输入不等于免审核。图片内容、提示词、输出视频以及当前账号权限仍由火山审核。Ovideo 保存的是可校验的生成来源，不向火山伪造任何“已授权”“免审核”参数，也不能保证每张图片或每次视频生成都被接受。

## 管理员配置

1. 在方舟开通 Seedream 5.0 Pro 和所需的 Seedance 视频模型权限。确认当前账号具备相应 API 额度。
2. 在后台“API 厂商配置”中为工作流生图配置官方方舟接口 `https://ark.cn-beijing.volces.com/api/v3`，模型选择 `doubao-seedream-5-0-pro-260628`。保持本系统接口路径配置与官方生图路径 `/images/generations` 对应。
3. 工作流 Seedance 视频配置使用同一方舟账号。Ovideo 的原图保护模式进一步要求**生图与视频使用完全相同的 API Key**：系统不能仅从两个不同的 Key 推断是否属于同一账号，因此采用更保守的同 Key 校验。这是本系统的校验方式，不是声称官方只允许同一个 Key。
4. 如果视频分为标准、Fast、Mini，或工作流与专业画布使用不同配置，应检查实际要使用的那一项。生图前检查工作流标准视频配置；提交视频时再次检查实际视频模型和使用范围对应的配置。
5. 不要把第三方转发接口或 Lite-only 套餐当作 Pro 使用。Pro 请求若实际解析为 Lite，会在生成前报错，不会静默降级并标成 Pro。
6. Key 只能保存在后台私密配置或环境中，不应写入源码、教程、截图或浏览器请求体。原图记录保存签名，不保存 Key。轮换 Key 后，旧图在本系统的保护模式下无法继续通过同 Key 签名校验；应重新生成，不要手工修改元数据延长有效期。

## 创作者操作

1. 打开本集的“镜头画面”，在默认模型或当前镜头模型中选择 **Seedream 5.0 Pro**。
2. 启用 **Seedance 人像分镜 · 纯文生图原图**。此开关对本集使用 Seedream 的镜头生效，包含批量生成；其他模型不受影响。
3. 检查画面提示词，明确人物外貌、服装、动作、场景和构图。开启该模式后，系统不发送已绑定参考图，也不会自动把当前已有的分镜结果作为图生图输入。素材绑定不删除，素材的文字描述可继续进入提示词。
4. 纯文生图不能保证复刻已有参考图片中的同一个人物。需要图生图时可关闭此模式，但不能把得到的图生图产物当成官方这项纯文生图受信原图。不要在没有上传图片时依赖“参考图 1”之类提示词。
5. 生成成功后，从系统中选择该分镜原图，继续进入视频生成。系统会保留文件 ID、原图 URL 和来源记录。不要把缩略图、屏幕截图、微信转发图或下载后编辑的图片替换成首帧或参考图。
6. 在有效期内，使用同一官方配置提交 Seedance。若某一输入被拒绝，先检查该任务的**所有**参考图片，而不是只检查首帧：混入另一张未经认可的人像图也可能使整个任务失败。

## 文件与状态契约

- 新的 Seedream 原始输出保留实际 PNG/JPEG/WebP 格式和字节，不再为存储统一转 WebP。
- `files.metadata.seedance_provenance` 保存实际请求的模型、纯文生图/图生图类型、参考图数、生成时间、30 天到期时间、官方接口标记、保护模式标记、原始文件 SHA-256 及签名。
- 原图来源由后端生成；前端传入的名称、模型标签或上传文件的备注不能充当来源证明。HMAC 签名用于检查记录和同 Key 使用情况，不代表火山签发的授权凭证。
- 保护模式的原图必须成功保存并登记文件 ID，才报告任务完成；保存或登记失败返回明确错误，不把临时输出当成可复用的成功分镜。
- Seedance 提交前按文件 ID 或已登记 URL 读取原图，对保护模式文件重新校验签名、模型、纯文生图类型、有效期和 SHA-256。传入 API 的 Base64 内容解码后与原图字节完全一致，不做缩放、JPEG 转码或质量压缩。
- 原图超过应用配置的输入大小限制时明确拒绝，不能通过自动压缩来假装保留原图。若需调整限制，应同时核对当前火山模型的单图、请求体、像素等限制及服务器容量。
- 历史图片继续作为普通参考输入处理，不补造历史来源，不回填假的生成时间。旧的 WebP 转换结果不能通过只修改后缀或标签恢复为受信原图。
- 遇到人像/内容审核拒绝或原图校验失败，任务停止自动重试；上游内容审核错误码在异步失败时仍被保留用于分类。单个素材的审核拒绝不标记整个模型通道不可用。
- 失败走现有任务失败与积分解冻逻辑；不修改定价，不新增成功扣费路径。真实账单以现有积分账本为准。

## 原图归档与验收

官方建议原始产物备份到 TOS，避免传播或压缩后失去原图特征。Ovideo 当前在自有文件存储中保留原始字节；运维另行备份到 TOS 时，应直接复制原文件，不通过图片处理样式、CDN 自动转码或重新编码。归档与下载不会重置 30 天期限。

上线验收应使用有权限的同一方舟账号进行一次实际“Pro 纯文生图 → 系统保存 → 页面重新打开 → 选择原图 → Seedance 视频完成”测试，并核对文件哈希、任务状态和积分流水。该测试会产生实际供应商费用和平台任务，请先取得使用账号及扣点授权。自动化回归使用模拟供应商响应验证保存、提交、失败和重试边界，**不能替代真实火山审核通过的证据**。

常见失败处理：

- 来源校验失败：核对实际生图、视频模型配置的 Key；检查是否切换了配置范围或轮换了 Key。
- 已超过 30 天：重新生成分镜，不能通过重新上传或修改日期延期。
- 文件已修改：恢复备份中的原始字节，或重新生成；不要将截图、缩略图、抠图、放大结果当原图。
- `InputImageSensitiveContentDetected.PrivacyInformation`：核查所有输入来源及当前模型/账号支持范围，必要时使用官方预置虚拟人物或依法授权的肖像素材库。不要反复提交同一被拒绝内容来绕过审核。
- Pro 通道不匹配：配置官方 Pro 模型，不要继续用只能处理 Lite 的通道。
