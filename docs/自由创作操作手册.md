# 自由创作操作手册

更新时间：2026-07-03

## 1. 功能定位

“自由创作”是项目内的无限画布模式，用来把剧本、图片、音频、视频等创作素材以节点方式自由组织起来。它不要求按“剧本 → 设计 → 配音 → 分镜 → 视频 → 美化 → 成品”的固定流程推进，适合做灵感草稿、镜头试验、画面生成、素材关系梳理。

入口路径：

- 分集列表页：点击某一集卡片上的“自由创作”。
- 流程化制作页：顶部导航里的“自由创作”。
- 直接地址：`/projects/{projectId}/ep/{episodeId}/canvas`。

## 2. 画布界面说明

| 区域 | 作用 |
|---|---|
| 左上角“返回分集” | 返回当前项目的分集列表。 |
| 左上角“流程化制作” | 回到当前分集的流程化制作入口。 |
| 右上角“+” | 添加节点。可添加剧本节点、图片节点、音频节点、视频节点。 |
| 右上角“删除选中” | 删除当前选中的节点或线条。 |
| 中上方状态提示 | 显示加载、保存、生成、错误等实时状态。 |
| 底部 AI 指令栏 | 选择 API / 本地 GPU 模式，并输入额外生成要求。 |
| 画布控制器 | 缩放、适配视图、查看小地图。 |

## 3. 节点类型

### 剧本节点

用于输入文字、剧本片段、画面描述、人物动作、镜头氛围等内容。

操作：

- 点击右上角“+”。
- 选择“剧本节点”。
- 在节点文本框中输入内容。
- 文本会自动保存，通常在停止输入后短暂延迟保存。

适合填写：

- 一段剧情。
- 一个镜头描述。
- 人物动作或对白。
- 画面风格、场景氛围。

### 图片节点

用于承载图片生成结果。

操作：

- 点击右上角“+”。
- 选择“图片节点”。
- 将剧本节点右侧圆点连接到图片节点左侧圆点。
- 点击底部“生成”或“GPU生成”。

生成完成后，图片会写入该图片节点并自动保存。

### 音频节点

用于承载和生成音频内容。

常用连线：

- `剧本节点 -> 音频节点`
- `剧本节点 -> 图片节点 -> 音频节点`

点击底部“生成音频”后，系统会读取上游剧本节点的文字并生成语音，完成后写入该音频节点。节点中有音频地址时，会显示播放器；没有音频时显示“暂无音频”。

### 视频节点

用于承载和生成视频内容。

常用连线：

- `图片节点 -> 视频节点`
- `图片节点 -> 音频节点 -> 视频节点`

点击底部“生成视频”后，系统会读取上游图片作为首帧参考提交视频任务。上游音频节点会保留在画布链路中，用于预览和后续合成规划，但当前不会直接作为 Seedance 视频输入提交。节点中有视频地址时，会显示播放器；没有视频时显示占位区域。

## 4. 基础操作流程

### 4.1 新建一个画面生成链路

1. 进入某一集的“自由创作”。
2. 点击右上角“+”，添加“剧本节点”。
3. 在剧本节点中输入画面描述。
4. 点击右上角“+”，添加“图片节点”。
5. 从剧本节点右侧圆点拖到图片节点左侧圆点，建立连线。
6. 在底部 AI 指令栏补充额外要求，例如“赛博朋克夜景，近景，强烈逆光”。
7. 选择生成模式。
8. 点击“生成”。
9. 等待状态提示变为生成完成，图片会出现在图片节点中。

### 4.2 继续生成音频和视频

在一条完整链路里：

```text
剧本节点 -> 图片节点 -> 音频节点 -> 视频节点
```

推荐操作：

1. 先点击“生成图片”。
2. 图片出现后，再点击“生成音频”。
3. 音频出现后，再点击“生成视频”。

如果没有明确选中节点，系统会优先生成链路里下一个还没有结果的节点。如果选中的是已经有图片的图片节点，并且下游音频为空，点击生成也会推进到音频；如果选中的是已经有音频的音频节点，并且下游视频为空，点击生成会推进到视频。

### 4.3 选择 API 或本地 GPU 生成

底部左侧有两个生成模式：

| 模式 | 说明 | 适用场景 |
|---|---|---|
| API | 使用外部图像 API 生成图片。默认模式。 | 快速出图，不依赖本地 GPU Agent。 |
| 本地 GPU | 使用 ComfyUI GPU Agent 生成图片。 | 想走本地工作流、需要本地 GPU 能力时。 |

使用本地 GPU 前，需要后台“集群节点监控”里有在线 GPU Agent。若没有在线节点，会提示“当前没有在线 GPU Agent”，此时可切回 API 模式。

### 4.4 删除节点或连线

删除节点：

1. 点击选中节点。
2. 点击右上角“删除选中”。
3. 或直接按 `Delete` / `Backspace`。

删除连线：

1. 点击线条选中。
2. 点击右上角“删除线条”。
3. 或直接按 `Delete` / `Backspace`。

删除节点时，与该节点相连的线条也会一并移除。

### 4.5 移动画布和节点

- 拖动节点：直接按住节点拖动。
- 缩放画布：使用鼠标滚轮或左下角控制器。
- 移动画布视角：拖动画布空白区域。
- 查看全局位置：使用小地图。

节点位置会在拖动停止后保存。

## 5. AI 生成规则

当前自动生成支持以下链路：

```text
剧本节点 -> 图片节点
剧本节点 -> 音频节点
剧本节点 -> 图片节点 -> 音频节点
图片节点 -> 视频节点
图片节点 -> 音频节点 -> 视频节点
```

图片生成时系统会组合三部分内容：

1. 剧本节点中的文本。
2. 底部 AI 指令栏里的额外要求。
3. 系统默认画面要求：高质量动漫/漫剧分镜风格、电影感构图、主体清晰、细节丰富。

音频生成时系统会读取上游剧本节点中的文字；如果没有上游剧本文字，会尝试使用底部 AI 指令栏中的文字作为朗读内容。

视频生成时系统会读取上游图片作为首帧参考，并读取底部 AI 指令作为镜头运动或风格补充。上游音频节点暂不直接传入 Seedance，避免把画布视频任务升级为不稳定的多模态请求。

如果剧本节点和底部 AI 指令都为空，点击生成会提示：

```text
请先在脚本节点或底部 AI 指令中输入要生成的内容
```

## 6. 推荐使用方式

### 方式一：单镜头快速试图

适合快速验证一个镜头画面。

1. 新建剧本节点。
2. 输入一段镜头描述。
3. 新建图片节点。
4. 连接剧本节点到图片节点。
5. 底部补充风格要求。
6. 点击生成。

### 方式二：同一剧情多版本试图

适合对同一段文字尝试多个画面版本。

1. 保留一个剧本节点。
2. 新建多个图片节点。
3. 将同一个剧本节点分别连到多个图片节点。
4. 选中目标图片节点或保持默认目标。
5. 多次调整底部 AI 指令并生成。

说明：如果一个剧本节点连接了多个图片节点，系统会优先使用当前选中的图片节点；如果没有选中图片节点，会使用找到的第一个“剧本 → 图片”连线。

### 方式三：灵感板整理

适合把想法、画面、声音、视频片段放在同一画布上做关系梳理。

1. 用剧本节点记录想法。
2. 用图片节点承载关键画面。
3. 用音频节点生成旁白或对白预览。
4. 用视频节点把图片和音频继续合成为短视频。
5. 用连线表达“来源、参考、结果、下一步”的关系。

## 7. 保存机制

自由创作画布会自动保存以下内容：

| 内容 | 保存时机 |
|---|---|
| 新增节点 | 创建节点后保存。 |
| 节点位置 | 拖动节点结束后保存。 |
| 剧本文字 | 停止输入后自动保存。 |
| 节点连线 | 创建连线后保存。 |
| 删除节点/连线 | 删除操作后同步删除。 |
| 图片生成结果 | 生成完成后写入图片节点并保存。 |
| 音频生成结果 | 生成完成后写入音频节点并保存。 |
| 视频生成结果 | 视频任务完成后写入视频节点并保存。 |

刷新页面后，系统会重新加载已保存的画布、节点和连线。

## 8. 当前限制

当前版本需要注意以下限制：

1. 画布加载按项目读取已有画布，当前同一项目下不同分集入口可能打开同一块自由创作画布。
2. 音频生成当前使用默认音色，暂未在自由创作页内提供音色选择面板。
3. 视频生成当前使用默认 Seedance Fast 参数，暂未在自由创作页内提供模型、时长、分辨率等高级设置。
4. 画布中暂未提供多画布切换、重命名、复制画布等界面操作。
5. 本地 GPU 生成只影响图片节点；音频和视频仍走对应的后端生成接口。
6. 本地 GPU 生成依赖 GPU Agent 在线；节点离线时需要切回 API 生成或先处理集群节点。

## 9. 常见问题

### 点击生成没有反应

检查：

- 是否已经建立了对应链路，例如“剧本 → 图片”、“剧本 → 音频”、“图片 → 视频”。
- 生成图片/音频时，剧本节点或底部 AI 指令是否至少有一处填写了内容。
- 生成视频时，上游图片节点是否已经有图片。
- 是否正在生成中。生成中按钮会显示“生成中”。

### 提示没有在线 GPU Agent

说明当前选择的是“本地 GPU”模式，但后台没有可用 GPU Agent。

处理：

- 切换到底部“API”模式再生成。
- 或前往后台“集群节点监控”确认 GPU Agent 是否在线。

### 连线看不到或点不中

处理：

- 从节点右侧圆点拖到另一个节点左侧圆点。
- 放大画布后再操作。
- 点击线条中段可选中线条，选中后线条会变为红色。

### 删除线条后刷新又出现

可能是删除请求失败或后端保存状态未同步。处理方式：

- 等待状态提示完成后刷新。
- 如果仍出现，重新选中线条删除一次。

### 文本改了但刷新后没保存

剧本节点文本是延迟自动保存。处理方式：

- 输入完成后停留片刻，等待自动保存。
- 如果状态提示“文本保存失败”，请刷新或重新登录后再试。

## 10. 建议工作流

如果希望从最少的节点开始，可在左侧“工作流模板”中点击“一键创建基础工作流”。
系统会创建三个已经连好的节点：

1. “输入剧本”：填写场景、人物、动作和台词，只保存文本，不产生积分消耗。
2. “生成首帧”：读取剧本，点击“生成”得到一张视频首帧。
3. “生成视频”：同时读取剧本和上一步图片，点击“生成”得到视频。

一键操作只负责创建和连接节点，不会自动提交付费生成任务。画布已有内容时会先确认，
替换后仍可使用撤销恢复。

日常推荐按下面顺序使用：

1. 先用流程化制作完成基础剧本或分集结构。
2. 进入自由创作，用剧本节点拆出想尝试的关键画面。
3. 用图片节点快速生成多版视觉草图。
4. 将满意的方向再带回流程化制作中的设计、分镜、视频阶段。
5. 对临时想法、替代镜头、风格探索，继续保留在自由创作画布中。

自由创作更适合“发散、试错、整理关系”；流程化制作更适合“稳定生产、批量生成、最终成片”。
