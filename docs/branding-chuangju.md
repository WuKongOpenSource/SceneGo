# 创剧品牌与内容规范

创剧是面向普通创作者的 AI 视频创作平台，对外服务地址为
`https://tv.ostory.ai`。域名属于部署与访问配置，不作为产品品牌名称展示。

## 核心表达

- 主名称：**创剧**
- 产品名称：**创剧 · AI 视频创作平台**
- 品牌主张：**把一个想法，变成一部好漫剧**
- 一句话说明：不用懂复杂工具，也能把创意、剧本、角色、分镜、画面、配音和剪辑一步步做成完整视频。

产品文案优先描述用户要完成的事情与下一步操作，避免把模型、节点、参数和技术架构放在首层。标准创作链路是：创意 → 剧本 → 角色与场景 → 分镜 → 画面与视频 → 配音与字幕 → 剪辑与成片。

创剧在产品界面、分享页、登录页和系统消息中作为独立产品出现，不展示母品牌名称或其他产品名称。产品矩阵关系由后续官网统一表达。

## 视觉识别

标志由圆角方形、场记板和播放三角组成。蓝色到紫色的渐变体现从创意到成片的连续过程，场记板直接表达短剧与视频制作。

- 浅色界面：`deploy/static/branding/chuangju-logo-on-light.svg`
- 深色界面：`deploy/static/branding/chuangju-logo-on-dark.svg`
- 紧凑位置：`deploy/static/branding/chuangju-mark.svg`
- PNG 与 favicon：运行 `python deploy/scripts/generate_ostory_brand_assets.py` 生成

内部兼容字段、数据库结构、域名和环境变量如果与既有运行协议绑定，可以保留，但不得作为用户可见文案。
