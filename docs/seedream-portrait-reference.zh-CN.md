# 真人文生图参考

## 使用方式

1. 在“定角色和场景”或“项目素材”的 AI 生图窗口选择 Seedream，在“素材用途”选择“人物四视图”或“纯背景”。输入文字描述，单次生成一张图，不发送任何参考图片；不会自动降级或切换其他模型。
2. 在视频卡片选择 Seedance 2.0 标准版、“全能参考”，勾选“真人文生图参考”。从素材库同时选取人物四视图和纯背景原图；需要配音时可沿用参考配音规则。此模式不接收参考视频。
3. 当前账户必须有素材与目标项目访问权限。两类图片必须由专用入口生成，实际返回模型经核实为 Seedream 5.0 Lite/Pro、零参考图片、生成后未满 30 天，原始字节未改变，且图片与视频通道为同一账号或已配置可信账号绑定。

这是输入资格校验，不代表上游审核通过或保证生成成功。请遵守人物肖像授权及服务商规则。

## 标签与资格

真人参考资格只接受实际模型核实且验签通过的 Seedream 5.0 Lite/Pro 纯文生图。图生图（包括只带一张参考图片）、外部上传、参考数量或生成模式不明、实际模型未核实的产物都不能因此获得资格。前端选择的模型不能作为来源凭证。
全站普通来源标签另行显示“模型名称 · 文生图/图生图”，包含项目素材、生成历史、分镜、视频参考和专业画布。Seedream、Gemini、GPT 等按服务端保存的生成模型与参考图快照分别显示；旧记录缺失方式时显示“方式待确认”，无可靠记录显示“来源待确认”，上传标为“外部上传”。普通标签不授予真人参考资格，也不将未知记录补写成纯文生图。

来源标签与当前视频资格分离：即使标签存在，仍须通过用途、原始 SHA-256、账号、时效和权限校验。历史图片不会自动补上用途；现有视频卡片和参考素材不会被自动删除、替换。修改用途名称或客户端字段不能将旧图、图生图变为合格素材。

## 实现和验证边界

新字段为 `reference_purpose`（人物四视图 / 纯背景）和 `portrait_reference_mode`（独立模式），保存在既有 JSON 元数据与任务数据中，无数据库迁移。用途和实际模型核实状态与原图 SHA 一起签名，兼容原有 v1/v2 签名校验，旧策略保持独立。

图像生产、可信原图持久化、两个任务提交服务以及共用在线执行器均有校验；排队后权限、文件或账号变更也会在执行前被拒绝。失败不自动重发付费请求。文生图来源接口只返回可读标签，不暴露签名、凭证或存储路径。

回归使用本地合成测试图片和模拟服务商返回，不消耗点数，也不代表已完成上游付费验收。
