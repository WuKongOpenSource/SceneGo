# 开源版支持政策

## 1. 不包含技术支持

SceneGo 开源版按许可证和仓库现状提供。公开发布方不为开源版提供任何形式的免费技术支持，也不承诺响应时限、修复时限、兼容性、可用性、性能、数据恢复或业务连续性。

不包含的支持范围包括但不限于：

- 操作系统、Python、Node.js、PostgreSQL、Redis、FFmpeg、反向代理和 TLS 的安装配置；
- 源代码编译、前端打包、数据库迁移、进程托管、升级和回滚；
- 云服务器、域名、证书、防火墙、网络代理、对象存储和 CDN；
- 第三方 AI、短信、邮件或支付平台的开户、认证、充值、配额和 API 调试；
- ComfyUI、模型权重、自定义节点、工作流、显卡驱动、CUDA、ROCm 和本地节点连接器；
- 二次开发、界面定制、数据修复、迁移、性能优化、故障排查和安全加固；
- 因第三方服务变更、地区限制、账号风控、内容审核或计费产生的问题。

公开 Issue、讨论区和代码评论不是服务台。是否回复、何时回复以及是否采纳均不构成支持承诺。

联系商业支持不代表服务已经成立；具体服务范围、交付物、费用、时间和责任边界以双方另行签署的书面协议为准。

## 3. 安全漏洞报告不是普通技术支持

负责任的安全漏洞报告应使用 `SECURITY.md` 中公布的私密渠道，不要在公开 Issue 中披露可利用细节、生产地址、凭据或个人数据。安全报告的接收不代表提供安装、配置或业务故障支持。

## 4. 使用者自助排查最小信息

使用者自行排查时应先记录：

- 所用公开版 Git 提交号；
- 操作系统和架构；
- Python、Node.js、PostgreSQL、Redis、FFmpeg 的版本；
- 执行到哪一步、预期结果和实际结果；
- 已脱敏的错误类别与时间；
- 是否能在全新测试环境复现。

不要公开发送完整 `.env`、数据库备份、访问令牌、带查询参数的媒体 URL、用户素材或第三方 API 原始响应。
